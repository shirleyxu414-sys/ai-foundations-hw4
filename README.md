# Campus Customs (HW4)

A shopping site for officially licensed Yale apparel with a built-in chatbot, "Bulldog Bot".
React + Vite + TypeScript front end, Python FastAPI back end, and a PydanticAI agent that answers
price and stock questions from a local database.

**All the code is in the [`hw4/`](hw4/) folder.**

- How to set up and run the front end and back end (after placing the data pack): [`hw4/README.md`](hw4/README.md)
- The agent itself is four files under `hw4/backend/`: `prompts/prompt.md`, `agent.py`, `tools.py` and `models.py`
- How the whole system works: [`hw4/output/harness.md`](hw4/output/harness.md)
- Prompts typed to the AI coding assistant, by problem: [`hw4/AI_prompts.md`](hw4/AI_prompts.md)
- Test report with screenshots: [`hw4/output/app_check.html`](hw4/output/app_check.html) (download the repo and open it in a browser)

The database, product photos and `.env` are local only and are not in this repository.
